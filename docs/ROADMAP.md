# Vibe Music — дорожная карта

Принцип: каждая фаза заканчивается приложением, которое можно потрогать на телефоне.

## P0 — Скелет + локальный источник ✅ (готово)
- Проект: Kotlin + Compose + Media3, тёмная тема в духе Qobuz
- Локальные треки (MediaStore): главная, поиск, воспроизведение
- Фоновый сервис + системное уведомление с контролами
- Контракт `SourcePlugin` — фундамент мультиисточниковости
- Плашка качества: `Quality` (LOSSY/LOSSLESS/HI_RES) + чип «FLAC»/«WAV» у трека
- Сборка: Gradle 9.1 + AGP 8.13 (под JBR 25 студии)

### Реальность по lossless (важно)
| Источник | Lossless? |
|---|---|
| Локальные файлы (FLAC/WAV) | ✅ уже с плашкой |
| YT Music | ❌ только lossy (AAC/Opus, до ~256 kbps) |
| SoundCloud | ❌ lossy AAC |
| Deezer | FLAC — только с собственной HiFi-подпиской пользователя |
| Qobuz / Tidal | ✅ честный FLAC/Hi-Res — только с собственной подпиской |

Бесплатного lossless из стримингов не существует — FLAC без подписки означает
чужой/взломанный аккаунт, это не делаем. «Lossless» в приложении = твои файлы
или твои же подписки (плагин Deezer/Qobuz/Tidal с логином пользователя, P5+).

## P1 — YT Music (ядро проекта) — 🔄 в работе (поиск+стрим готовы)
- ✅ InnerTube-клиент: поиск (WEB_REMIX, фильтр «Песни»), проверено живыми запросами
- ✅ Резолв потоков: fallback-цепочка ANDROID → IOS (без логина; остальные клиенты YouTube
  закрыл: LOGIN_REQUIRED / PoToken). Поток проверен: HTTP 206, opus 251 ~153 kbps
- ✅ Обложки грузятся автоматически (thumbnail → w544-h544), общий поиск: локальные + YTM
- ⏳ Дальше: страницы альбомов/исполнителей, радио и очередь, авторизация (опционально)
- ⚠️ Помнить: качество максимум lossy ~256 kbps — lossless тут физически не бывает

## P2 — Библиотека ✅ (ядро готово)
- Room: избранное (сердечко в плеере + долгий тап), плейлисты (создание/удаление,
  добавление треков из любого списка долгим тапом), детали плейлиста с «играть очередью»
- Очередь на уровне приложения: след./пред., автопереход по окончании трека
- ⏳ Дальше: полноценная очередь в ExoPlayer (след./пред. в системном уведомлении),
  перемешивание, история прослушиваний

## P3 — SoundCloud ✅ (готово, опережая план)
- Плагин SoundCloud: client_id из бандлов веб-плеера, поиск, стримы
- progressive mp3 128 kbps, для треков без него — HLS (media3-hls)
- Автообновление устаревшего client_id; обложки t500x500; шеринг permalink'ом

## P1.5 — PoToken для YT Music (критично!)
- YouTube закрыл анонимные стримы для клиентов ANDROID/IOS (сент. 2026, подтверждено)
- План: генерация PoToken на устройстве через WebView + BotGuard (подход NewPipe),
  подключение токена к player-запросам; пока YT играет только на «чистых» IP

## P4 — Оффлайн
- Media3 CacheDataSource (кэш прослушанного)
- Загрузки через DownloadService («скачать и слушать без сети»)

## P5 — Deezer / VK
- Deezer: метаданные через публичный API, стрим — отдельная задача
- VK: неофициальный клиент (официальный audio API закрыт для сторонних)
